# ユースケース

Markuplintで特定の課題を解決するための実践的な設定例です。各ユースケースには、問題の説明、正しい/誤ったコード例、そのままコピーして使える設定を含みます。

## プロジェクトのセットアップ

- [Reactプロジェクト](/docs/configuration/usecases/react-project) — パーサー、スペック、プリテンダーを使ったReact（JSX/TSX）のセットアップ
- [Vueプロジェクト](/docs/configuration/usecases/vue-project) — パーサー、スペック、プリテンダーを使ったVueのセットアップ
- [モノレポ](/docs/configuration/usecases/monorepo) — パッケージごとのオーバーライドで設定を共有
- [CI/CD連携](/docs/configuration/usecases/ci-cd) — GitHub Actionsでの実行と段階的な導入戦略

## ルール設定

- [アクセシビリティルールのカスタマイズ](/docs/configuration/usecases/accessibility) — 深刻度の調整、特定ルールの無効化、a11yプリセット単体での利用
- [CSS設計](/docs/configuration/usecases/architected-css) — BEMのようなクラス命名規則をコンポーネント単位で適用
- [一貫した画像ファイル名](/docs/configuration/usecases/consistent-image-file-naming) — レスポンシブ画像のファイル名に一貫した命名パターンを適用
