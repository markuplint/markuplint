# `@markuplint/rule-textlint`

`@markuplint/rule-textlint` は削除されました。アンインストールし、Markuplint 設定から `textlint` を消してください。

HTML 内テキストは [textlint](https://textlint.github.io/) と [`textlint-plugin-html`](https://github.com/textlint/textlint-plugin-html)。Markdown を Markuplint で見るなら `@markuplint/markdown-parser`。
