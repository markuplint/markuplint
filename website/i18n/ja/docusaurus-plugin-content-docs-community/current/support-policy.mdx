# サポートポリシー

Markuplint は、同時に最大 3 つのメジャーバージョンを扱います。現在の安定版、1 つ前の LTS（長期サポート）版、開発中の次のバージョンです。

| バージョン | 状態         | 受け取るもの                                                       | npm の dist-tag | Node.js       |
| ---------- | ------------ | ------------------------------------------------------------------ | --------------- | ------------- |
| v6         | Experimental | 開発中の次のメジャーバージョン。互換性のない変更がいつでも入ります | 未リリース      | v26 以降      |
| v5         | Stable       | 新機能、バグ修正、依存パッケージの更新                             | `latest`        | v24 以降      |
| v4         | LTS          | セキュリティ脆弱性の修正のみ                                       | `v4`            | v18.18.0 以降 |

## サポート期間

サポートするのは、現在の安定版とその 1 つ前の 2 つのメジャーバージョンです。次のメジャーバージョンが安定版としてリリースされると、すべての状態が 1 段ずつ進みます。LTS 版はサポート終了になり、安定版は LTS 版に、Experimental 版は安定版になります。v6 が安定版としてリリースされたときに、v4 のサポートは終了し、v5 が LTS 版になります。

サポートを終了したバージョンは、セキュリティ修正を含め、以後リリースされません。パッケージは npm に残ります。

## 修正が届くまで

- **依存パッケージの脆弱性**は、修正版が公開され次第、サポート中のすべてのバージョンで修正します。
- **それ以外の依存パッケージの更新**は、安定版と Experimental 版だけが、公開から 7 日経ったものを取り込みます。LTS 版はそれ以外の更新を取り込まないため、依存パッケージの範囲や対応する Node.js のバージョンは変わりません。
- **リリース**: サポート中のバージョンに入った修正は、数日以内にリリースします。npm の利用者に届く変更がリリースされないまま 3 日経つと、リポジトリが自動で Issue を立てます。

## 脆弱性の報告

脆弱性は公開の Issue で報告しないでください。非公開で報告する方法は[セキュリティポリシー](https://github.com/markuplint/markuplint/security/policy)を参照してください。
