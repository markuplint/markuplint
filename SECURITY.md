# Security policy

## Supported versions

| Version      | Status       | Security fixes        |
| ------------ | ------------ | --------------------- |
| v6           | Experimental | No (prereleases only) |
| v5           | Stable       | Yes                   |
| v4           | LTS          | Yes                   |
| v3 and older | End of life  | No                    |

How long each version is supported, and what else it receives: [Support policy](https://markuplint.dev/community/support-policy).

## Reporting a vulnerability

Do not open a public Issue. Report it privately through GitHub: [Report a vulnerability](https://github.com/markuplint/markuplint/security/advisories/new). Include the affected version, how to reproduce it, and the impact you expect.

A fix is released for every supported version that is affected, and the advisory is published with the release.
