# `@markuplint/rule-textlint`

The `@markuplint/rule-textlint` package is removed. Uninstall it and delete the `textlint` entry from Markuplint config.

Use [textlint](https://textlint.github.io/) with [`textlint-plugin-html`](https://github.com/textlint/textlint-plugin-html) for HTML text, and/or `@markuplint/markdown-parser` if you lint Markdown with Markuplint.
